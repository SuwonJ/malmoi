## 실험에서 확인한 것

평가 질의는 **4개**이며 여러 방법을 비교한 개발용 탐색 결과다. nDCG@10은 관련성 등급을 반영한 순위 품질, Hit@10은 등급 3 정답을 상위 10개에 포함한 질의 비율이다. 라벨 밖의 결과는 0으로 취급하므로 사람의 추가 판정도 필요하다.

### 전체 사전 검색

| 방법 | nDCG@10 | Hit@10 | 호스트 지연 ms | 측정 범위 |
| --- | ---: | ---: | ---: | --- |
| 문자 TF-IDF | 0.4050 | 25% | 13.3 | 반복 측정 p95 |
| E5 + 문자 RRF | 0.3637 | 50% | 88.0 | 단계별 지연 합산 추정 |
| Kiwi TF-IDF | 0.3008 | 0% | 4.2 | 반복 측정 p95 |
| Kiwi BM25 | 0.2902 | 0% | 3.0 | 반복 측정 p95 |
| E5 + 문자 → BGE 단어·뜻풀이 재순위화 | 0.2722 | 50% | 3815.0 | 검색·재순위화 단계 합산 추정 |
| E5-small int8 | 0.2081 | 25% | 41.7 | 반복 측정 p95 |

현재 전체 검색 비교에서는 문자 TF-IDF가 nDCG 기준선이다. E5 결합은 Hit@10을 높였지만 nDCG는 낮아, 한 지표만으로 대체를 결정하기 어렵다. BGE 재순위화도 이 개발셋에서는 기준선을 넘지 못했다.

수치 출처: [전체 결과 CSV](progress/2026-10-20/quality_summary.csv). 어휘 검색 CPU 1스레드, ONNX 추론 4스레드 기준이다. 지연은 최초 모델 로드·오프라인 문서 임베딩 생성을 제외한다. 단계별 p95의 합은 통합 p95 실측이 아니다.

### 고정 후보 풀 재평가

문자/E5 각각 상위 200개 단어에서 얻은 뜻풀이 합집합을 같은 후보 풀로 사용했다. 문항당 358–377개 뜻풀이, 중복 제거 문장 총 1,237개이며 정답을 강제로 추가하지 않았다.

| 모델 | nDCG@10 | Hit@10 | 문서 캐시 시 질의 p95 ms |
| --- | ---: | ---: | ---: |
| KURE-v1 int8, CLS | 0.6197 | 100% | 20.7 |
| Qwen3-Embedding-0.6B int8, 지시문 사용 | 0.1532 | 25% | 58.5 |
| Qwen3-Embedding-0.6B int8, 지시문 없음 | 0.2895 | 50% | 38.1 |

KURE가 후보 재평가에서 가장 유망하다. 다만 전체 사전 dense 검색 결과가 아니며, 시간에는 앞단 후보 검색·최초 모델 로드·캐시 미스 문서 생성이 빠져 있다. 위 전체 검색 표와 동일한 검색 범위나 시간 조건으로 해석하면 안 된다. **최종 모델 확정과 모바일 5초 목표 달성은 아직 판단하지 않는다.**

## 검증과 재현 상태

2026-10-20 현재 로컬 연구 폴더에서 다음 명령으로 **단위 테스트 10개 통과**를 확인했다. 표제어 정규화, Hit/Recall 구분, 역색인 점수 일치, 중복 처리, 부정 표현 보존, BM25 계산, RRF, 모델별 풀링/지시문 처리를 검증한다. C 빌드나 전체 모델 실험을 이번 문서 작업에서 다시 실행한 것은 아니다.

```bash
.venv/bin/python -m unittest discover -s tests -v
```

기존 실험 실행 명령은 아래와 같다. 이제 코드가 `research/`에 반입되어 있다. 저장소 루트에서 `make setup`, `make test`, `make smoke`로 기본 동작을 확인한다. 아래 전체 실험은 `research/`에서 실행하며 사전·모델을 별도로 준비한다. 인코더 비교에는 `--base experiments/runs/<새 advanced 실행 ID>`를 추가한다.

```bash
.venv/bin/python -m src.experiment_suite
.venv/bin/python scripts/run_quality.py
.venv/bin/python scripts/run_encoder_comparison.py
.venv/bin/python scripts/try_models.py --models char kure --query "아주 조금 내리는 비"
```

공유 범위는 연구 소스·스크립트·테스트·평가셋·결과 요약과 과거 실행 보고서/메타데이터까지 확장했다. [반입 출처와 소스 해시](../research/IMPORT.json)를 기록했고 원래 로컬 작업 트리는 보존했다. [초기 결과 스냅샷](progress/2026-10-20/sources.json)은 요약 작성 당시 자료다. 원본 사전·모델·생성 벡터·전체 후보 문서는 포함하지 않는다. 과거 실행은 `research/experiments/runs/`에서 열람하며 새 전체 모델 비교는 데이터를 준비한 뒤 다시 실행한다.

반입 후 단위 테스트 10개와 예제 사전의 7개 어휘 검색 설정 실행을 확인했다. 예제는 실행 확인용이며 실제 검색 품질 근거에 합산하지 않는다.
